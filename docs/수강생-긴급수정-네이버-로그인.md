# [긴급 수정] 네이버 로그인이 계속 안 될 때

> **강의 영상 촬영 이후 네이버가 화면을 바꿔서 생긴 문제입니다.**
> 수강생분 잘못도, 프롬프트가 틀린 것도 아닙니다. 아래 내용을 복사해서 붙여넣으면
> 5분 안에 해결됩니다.

---

## 이런 증상이면 이 문서가 맞습니다

- "네이버 로그인" 버튼을 누르면 브라우저 창은 잘 뜨고, **로그인도 정상적으로 됩니다.**
- 그런데 대시보드 화면에는 계속 **"로그인 안 됨"** 으로 남아 있습니다.
- 몇 번을 다시 로그인해도 똑같습니다.
- 그 상태에서 "네이버 에디터에 자동입력"을 누르면 **아무 일도 일어나지 않습니다.**

## 왜 이런 일이 생겼나요?

프로그램은 로그인이 끝나면 "내 블로그 주소가 뭔지" 알아내야 합니다. 그래야 글쓰기
화면을 열 수 있으니까요.

이때 `blog.naver.com` 으로 이동해서 주소창을 읽는 방식을 썼는데, **예전에는 여기가
내 블로그로 연결됐지만 지금은 남의 글이 뜨는 홈피드로 연결됩니다.** 그 페이지에는
내 블로그 아이디가 어디에도 없습니다.

그래서 로그인은 성공했는데 아이디를 못 찾고 → 로그인 기록이 저장되지 않고 →
화면에는 계속 "로그인 안 됨"으로 남습니다.

> 이런 일은 앞으로도 생길 수 있습니다. 네이버 같은 외부 서비스를 자동으로 다루는
> 프로그램은 **상대가 화면을 바꾸면 같이 고쳐줘야 합니다.** 내 코드는 한 줄도
> 안 건드렸는데 어느 날 갑자기 안 되는 게 정상입니다.

---

## 해결 방법

내 프로젝트 폴더에서 Claude Code를 켜고, **아래 회색 상자 안의 내용을 통째로
복사해서 붙여넣으세요.**

```
내 네이버 블로그 자동화 프로젝트에서 네이버 로그인이 끝내 완료되지 않는 문제를
고쳐줘.

[증상]
로그인 창에서 로그인은 정상적으로 되는데, 앱 화면에는 계속 "로그인 안 됨"으로
남아 있어. 그 상태에서 자동입력을 누르면 아무 일도 일어나지 않아.

[원인]
로그인 후 내 blogId를 알아내려고 https://blog.naver.com/ 으로 이동하는 코드가
있을 거야. 예전에는 여기가 로그인한 사람의 블로그로 리다이렉트됐지만, 지금은
남의 글이 뜨는 홈피드(section.blog.naver.com/BlogHome.naver)로 이동해. 그
페이지에는 내 blogId가 어디에도 없어서 탐지에 실패하고, 세션이 저장되지 않아
계속 로그인 안 된 상태로 남는 거야.

[이렇게 고쳐줘]
1. blogId를 찾을 때 https://blog.naver.com/MyBlog.naver 로 이동해. 이 주소는
   지금도 내 블로그(https://blog.naver.com/<blogId>)로 정확히 리다이렉트돼.
2. blogId는 도착한 페이지의 주소(URL)에서 뽑아 — blog.naver.com/<blogId> 형태의
   경로에서 읽으면 돼.
3. 중요: 페이지 HTML을 뒤져서 blog.naver.com/<아이디> 형태의 링크를 긁는 방식은
   절대 쓰지 마. 홈피드 HTML에는 모르는 사람들의 블로그 링크가 가득해서, 그걸
   긁으면 남의 블로그 아이디를 내 것으로 저장해버릴 수 있어. ?blogId= 쿼리
   형태를 보조로 쓰더라도 blog.naver.com 도메인에 있을 때만 봐.
4. MyBlog, BlogHome, PostList, PostView, market, blogpeople 처럼 네이버가 쓰는
   고정 경로는 blogId로 오인하지 않게 걸러줘.

다 고친 뒤에 실제로 로그인 버튼을 눌러서 "로그인 완료: <내 블로그 아이디>"까지
뜨는지 확인해줘.
```

---

## 잘 고쳐졌는지 확인하는 법

대시보드에서 **"네이버 로그인"** 버튼을 누르고, 화면의 검은 로그 상자를 보세요.
이렇게 나오면 성공입니다:

```
[info] 저장된 세션을 확인하는 중...
[info] 블로그 아이디를 확인하는 중...
[done] 로그인 완료: 내블로그아이디        ← 이 줄이 뜨면 끝
```

버튼 위쪽 표시도 **"로그인됨"** 으로 바뀌고 내 블로그 아이디가 같이 보입니다.

> 문구는 프로젝트마다 조금씩 다를 수 있습니다. **핵심은 마지막에 내 블로그
> 아이디가 찍히고, 화면 표시가 "로그인됨"으로 바뀌는 것**입니다.

### 로그인 창이 다시 뜨면?

정상입니다. 저장해둔 로그인 정보는 며칠 지나면 만료돼서, 그때는 다시 한 번
로그인해야 합니다. **그 창에서 직접 아이디·비밀번호를 입력하세요.**
(이 프로그램은 아이디·비밀번호를 대신 입력하지 않습니다 — 그렇게 만들어져 있습니다.)

---

## 그래도 안 되면

로그 상자에 뜬 **마지막 줄을 그대로 복사해서** Claude Code에게 보여주세요.
특히 이런 줄이 있으면 함께 알려주시면 좋습니다:

```
[error] 블로그 아이디를 확인하지 못했습니다 (현재 페이지: ... )
```

괄호 안의 주소가 **네이버가 지금 어디로 보내고 있는지**를 알려주기 때문에,
그것만 있으면 원인을 바로 찾을 수 있습니다.
